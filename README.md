# gtfs-diff-web
Une vraie page HTML autonome, qui tourne entièrement dans le navigateur. Un fichier .html (plus quelques fichiers) que l’utilisateur ouvre directement : il choisit deux ZIP GTFS, et tout le calcul se fait dans le navigateur, sans serveur, sans Python, sans exe, et sans aucune connexion sortante quand on compare des fichiers.
